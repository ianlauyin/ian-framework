# Rust Framework

This file is the catalog of the Rust library in `framework_rs/`.

- The decision records a behaviour that the code does not show. 
- Update that row in the same change when you make a new decision, the entry moves, or you add or remove a feature. 
- When a code change would change the decision and you did not make that decision, stop and ask. Leave the decision as it is.

| Path | Description | Decision |
| --- | --- | --- |
| `framework_rs/src/logging/` | Request and event logging | `record` writes an event to the logger. When no logger is set, `record` writes the event to `tracing`, so an event before the logger starts is not lost. `Logger` accepts each `LogShipper`, so the log server can write its events to its database. An authorized POST is trusted, so the log server stores the `context` and the `extra` that the project sets. A flush stops after three failed batches, so a down log server does not keep the process open. `with_log` sets the latency after it builds the event, so the builder cannot replace the latency. The default mask patterns hide a credential in a field name and in a name-value pair, because the access log records the query and the JSON body. A name-value pair is `name=value`, a JSON member, or a name, a colon, a space, and the text to the end of the line. The mask replaces the full pair. In a string value and in `error_message`, the mask replaces only a name-value pair, so a path, an error code, or a file name that contains a pattern stays. The mask does not change `action`. Each tick of the ship loop sends chunks until the buffer is empty or a chunk fails. |
| `framework_rs/src/monitor/` | CPU and disk monitors | Disk usage follows `df`. The blocks that root cannot use are not free, and the blocks that only root can use are not counted. |
| `framework_rs/src/gcp/storage/` | Google Cloud Storage client | The official crates own authentication, token refresh, and retries. `connect_with_adc` builds a URL signer. With no signer email, the signer is the account of the credentials, and that account must be a service account or the metadata server. `connect_public_with_adc` is for a public bucket. It builds no URL signer, so it works with any credentials. Its `sign_download_url` returns `SIGNER_MISSING`, and the caller uses `public_url`. An object name longer than 1024 bytes is refused, because GCS refuses a longer name. `merge_object_metadata` writes only when the metageneration did not change after the read, and it tries 3 times, so a concurrent write is not lost. |
| `framework_rs/src/http/` | HTTP boundary error, request header helpers, safety and security middleware, the version route, the health route, the SPA route, and the browser log route `POST /log` | The access log writes `ip`, `user_agent`, and `request_url` after the handler fields, so a handler cannot replace those keys. When `Sec-Fetch-Site` is absent, the check compares `Origin` with `Host`, because a browser that does not send `Sec-Fetch-Site` still sends `Origin` on a POST. The cookie reader reads every `Cookie` field, because an HTTP/2 client can send each cookie in its own field. A bearer key compare uses the SHA-256 hashes, because slices of different lengths compare in less time. A full rate-limit map drops a batch of the least recently used buckets at one time, so a full scan is rare. The `on_reject` function is `Send` and `Sync`, so two calls can run at the same time. The allowed IP list accepts an address or a CIDR range, and it refuses a range with host bits set, because such a range is usually a typo. An IPv4-mapped IPv6 address does not match an IPv4 range. The client IP is the `CF-Connecting-IP` header only, so the server must accept traffic only from Cloudflare. If a client can reach the server directly, that client can set the IP for the allowed IP list, the rate limit, and the access log. The action of the access log is the route pattern, so one route gives one action. When no route matches, the action is the request path. When the request stops before the response, the access log records a warning. The SPA route gives 404 for a missing path whose last segment contains a dot, because that path is a file and not a page. Thus a page path cannot have a dot in its last segment. `require_session` writes the `subject` of the session to the context of the access log, so a request of a session shows its subject. The browser log route sends the events to the log shipper before it gives the response, so the browser can send the events again after a failure. When no logger is set, the route writes the events to `tracing`. The browser log route allows a burst of 300 requests and then 10 requests each second from one IP address, because the route has no authentication and many browsers can share one IP address. A browser event can have `errorName` and `stack`. The route puts the name before the error message and the stack after it, so the log server needs no new field. An event that has no error message does not keep the name or the stack. When the request has no client IP, the `ip` is `-`. |
| `framework_rs/src/http/sse.rs` | Server-sent events from a broadcast channel, feature `sse` | `broadcast_sse` sends each message as one JSON event. A receiver that lags skips the lost messages and sends the next message. The client gets no sign of the lost messages. A message that cannot become JSON is skipped. The stream ends at shutdown, so an open stream does not stop the graceful shutdown. The stream also ends when all senders close. |
| `framework_rs/src/token.rs` | RFC 9110 `token68` check | A project can use the check to reject an API key at startup. |
| `framework_rs/src/redis.rs` | Redis connection helper | The connection fails fast when Redis is down. It does not retry for many seconds. |
| `framework_rs/src/auth/` | Cookie sessions and password hashes | A Redis key holds the hash of the token, so a copy of Redis does not give a working token. The subject set key is a hash of the subject, so the subject cannot change that key. The session TTL is at most 400 days, because a browser caps a cookie lifetime at 400 days. The session TTL is the idle timeout, and each load starts it again. A session also ends at the absolute TTL after its start, also when it is in use, because OWASP tells that each session has an idle timeout and an absolute timeout. The absolute TTL is not less than the session TTL. The Redis value holds the subject and the end time as JSON. A session that has no end time gets the absolute TTL at its first load, so no session is without a limit. The session cookie and the clear cookie use the same attributes, `HttpOnly`, `Secure`, `SameSite=Lax`, and `Path=/`, because a browser removes the cookie only when the attributes match. The subject set gets the session TTL each time a session of the subject starts or loads, in the same transaction as the expiry of the session. Thus the set does not expire before its sessions, and a subject that does not come back leaves no key. `create` runs as one script, so two sessions that start at the same time do not go above the session limit. `remove_subject` runs as one script, so a session that starts at the same time is removed or is fully made after the removal. `verify_password` refuses only a password that is too long, so a change of the password rules does not lock out a user who has an old password. A password hash runs on a blocking thread, because Argon2 uses much CPU time. |
| `framework_rs/src/exception.rs` | Shared error type `Exception` | The message and `Debug` do not show the source, because the source can hold a secret. |
| `framework_rs/src/shutdown.rs` | Shutdown signal `ShutdownReceiver` | `wait` returns a `'static` future that owns its receiver, so the caller does not borrow `ShutdownReceiver`. |
| `framework_rs/src/mutex.rs` | Standard mutex lock | |
| `framework_rs/src/env.rs` | Environment variable read helpers | The error holds the name and does not hold the value, because the value can be a secret. |
| `framework_rs/src/gcp/` | Shared Google Cloud code and Secret Manager access | The official crates read Application Default Credentials. The project chooses the fallback from Secret Manager to an environment variable. The library reads `GOOGLE_CLOUD_PROJECT`, which is a Google Cloud standard variable and not an app setting. An error does not hold the secret value or a parser error that can quote it. With no `GOOGLE_CLOUD_PROJECT`, a failed connection to the metadata server means that the process is not on Google Cloud, and the library does not try again. A different failure of the metadata server is tried 3 times. |
| `framework_rs/src/time/` | Hong Kong time `hkt_now` and `hkt_today`, and `Quarter` | Hong Kong time is the fixed offset UTC+08:00, and it has no daylight saving time. `first_day` and `last_day` return text of the year, the month, and the day, because the stored day is that text. |
