# Framework features

This file is the index of framework feature documents.

Request and event logging is `spec/framework/logging.md`.
The shipper posts each batch to `/log/{app}`.
`app` is the routing name.
The Google Cloud Storage client is `spec/framework/gcs.md`.
The HTTP boundary error is `spec/framework/http.md`.
Cookie sessions and password hashes are `spec/framework/auth.md`.
